### 1B PR1 — Engine shell: Done

### 1B PR2 — Normalize public output: Done

- `Approved(ApprovedExecution)` — effective_risk_state, pending_reservation_id, adjusted_min_edge_usd

`GateResults` is not in the public output.

### 1B PR3 — Normalize public input: Done

Engine-level domain input types are public:
- `OpenExecutionInput` (with `LiquidityExecutionInput`, `NetEdgeExecutionInput`, `PricerExecutionInput`, `InventorySkewExecutionInput`)
- `CloseExecutionInput`, `HedgeExecutionInput`, `CancelExecutionInput`
- Private builder functions inside `engine.rs` translate these to internal gate types

All internal wire types are `pub(crate)`:
- `LiquidityGateInput`, `NetEdgeInput`, `PricerInput`, `IntentPipelineInput`, `OpenRuntimeInput`,
  `QuantizePipelineInput`, `PipelineResult`, `OpenRuntimeOutput`
- Both orchestration functions (`evaluate_intent_pipeline`, `build_open_order_intent_runtime`) are `pub(crate)`
